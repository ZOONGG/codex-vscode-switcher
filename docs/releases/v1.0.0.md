Codex VS Code Switcher v1.0.0 is the first stable release of the standalone Windows profile switcher.

### Highlights

- Switch between real Codex accounts with a dedicated `CODEX_HOME` for every profile. Switching is serialized and transactional, supports repeated A → B → C → A cycles, verifies the new VS Code window, and restores the previous profile after a failed launch.
- Run Codex in a managed VS Code environment with isolated user data, shared ordinary extensions by default, and an optional fully isolated extensions directory.
- Restore the current folder or `.code-workspace` across profile changes and restarts, with a first-launch project chooser and recent-project recovery actions.
- Open the Codex sidebar automatically through the bundled companion extension. `Ctrl+Alt+C` and the `Codex` status-bar action reopen it on demand.
- Use the floating overlay in Auto, Compact, or Expanded mode. Settings provides a live preview for layout, orientation, width, scale, offsets, and placement.
- Diagnose VPN and networking issues with sanitized DNS, TCP, TLS, HTTPS, WebSocket, and backend checks; compare regular and managed VS Code; copy allowlisted proxy settings; and configure a custom CA path.
- Import an allowlisted subset of VS Code settings and create a separate Codex VS Code shortcut without copying credentials, sessions, cookies, storage databases, or machine identifiers.

### Safety and privacy

- The app is local-only and telemetry-free.
- Profile authentication files are never copied between profiles or included in release artifacts.
- Managed-window identity requires the expected executable, launch arguments, process tree, PID/start time, and visible top-level window.
- Normal profile switching closes only the verified managed VS Code instance and does not force-kill ordinary VS Code windows.

### Downloads

- `CodexVsCodeSwitcher.exe` — standalone self-contained Windows x64 executable.
- `CodexVsCodeSwitcher-win-x64-portable.zip` — complete portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 checksums for both artifacts.

Requirements: Windows 10/11 x64. Visual Studio Code and the official OpenAI Codex extension are required for managed Codex sessions.
