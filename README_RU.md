# Codex VS Code Switcher

Codex VS Code Switcher — независимое Windows-приложение для запуска одного изолированного управляемого экземпляра Visual Studio Code с выбранным профилем Codex.

Программа не переключает ChatGPT Desktop, не заменяет общий файл авторизации и не управляет обычными окнами VS Code.

## Изоляция

Управляемый экземпляр всегда запускается так:

```text
Code.exe
  --user-data-dir "%LOCALAPPDATA%\CodexVsCodeSwitcher\VSCodeData"
  --extensions-dir "%LOCALAPPDATA%\CodexVsCodeSwitcher\VSCodeExtensions"
  --shared-data-dir "%LOCALAPPDATA%\CodexVsCodeSwitcher\VSCodeSharedData"
  --new-window
  [необязательная папка или .code-workspace]
```

`CODEX_HOME` добавляется только в `ProcessStartInfo.Environment` этого запуска и указывает прямо на выбранный каталог в `%USERPROFILE%\.codex-vscode-profiles`. Профиль и `auth.json` не копируются и не заменяются.

Изменяемые данные находятся только в:

```text
%LOCALAPPDATA%\CodexVsCodeSwitcher
%USERPROFILE%\.codex-vscode-profiles
```

Защищённые каталоги:

```text
%USERPROFILE%\.codex
%LOCALAPPDATA%\CodexProfileOverlay
```

## Проверка управляемого экземпляра

Окно считается управляемым только при одновременном выполнении условий:

- совпадают сохранённый root PID и время запуска процесса;
- точно совпадает путь к настроенному или найденному VS Code;
- в командной строке root-процесса есть точные отдельные `--user-data-dir`, `--extensions-dir` и `--shared-data-dir`;
- окно принадлежит root-процессу или проверенному потомку;
- HWND остаётся видимым окном верхнего уровня этого дерева процессов.

Одного имени `Code.exe` недостаточно. Заголовок окна не используется как идентификатор.

## Поведение панели

Панель больше не является глобальным окном поверх всех приложений. События foreground, сворачивания/восстановления, уничтожения, показа/скрытия и перемещения отслеживаются Win32 hooks; раз в две секунды выполняется защитная сверка.

По умолчанию панель:

- видна только вместе с foreground-окном управляемого VS Code;
- не исчезает при работе с собственными кнопками и меню;
- скрывается поверх ChatGPT, браузеров, Проводника, обычного VS Code, других редакторов, представления задач, чужих полноэкранных приложений и защищённых рабочих столов;
- скрывается при сворачивании или закрытии управляемого окна;
- возвращается после восстановления и фокусировки управляемого окна.

Сохранены режимы «Авто», «Компактный», «Развёрнутый», перетаскивание, масштаб, смещения, DPI, несколько мониторов и сброс положения.

Открытие Настроек создаёт явную интерактивную preview-сессию. Раскладка, ориентация, ширина, масштаб, смещения и положение меняются сразу, даже если Codex VS Code не запущен. После закрытия Настроек немедленно возвращается видимость только с проверенным окном Codex VS Code; preview не привязывается к окну Настроек и не запускает профиль.

## Переключение профиля

Переключения сериализованы и выполняются транзакционно:

1. проверяются профиль, exe, отдельные каталоги, расширение и workspace;
2. штатное закрытие отправляется только проверенным окнам управляемого VS Code;
3. программа ждёт VS Code и подтверждение несохранённых файлов;
4. новый экземпляр запускается с выбранным профилем и изолированными аргументами;
5. успех требует действительного процесса и видимого проверенного окна;
6. активный профиль сохраняется только после этой проверки;
7. при ошибке запуска один раз открывается предыдущий профиль.

Обычный процесс переключения не использует принудительное завершение.

Щелчок по профилю запускает этот сценарий напрямую. Выбранный профиль помечается как ожидающий и становится активным только после проверки нового окна. Успех, ошибка, тайм-аут и отмена всегда освобождают блокировку и снова включают кнопки профилей.

## Расширение Codex и workspace

В отдельной среде определяется официальное расширение `openai.chatgpt`. Установка начинается только после явного действия **«Установить расширение Codex»** и использует только отдельный каталог расширений.

Отдельный `User\settings.json` обновляется атомарно с сохранением остальных корректных настроек. `chatgpt.openOnStartup` задаётся только там.

Можно выбрать папку, файл `.code-workspace` или пустое окно. Исчезнувший сохранённый workspace не удаляется без явного действия пользователя.

**«Импортировать мои настройки VS Code»** — необязательное действие с предварительным подтверждением. Оно показывает разрешённые settings, keybindings, snippets, файлы именованных профилей и число расширений. Базы хранилищ, сессии, учётные данные, cookies, machine ID, журналы и временные файлы не копируются. Выбранные расширения устанавливаются отдельно только в выделенный каталог.

**«Сбросить состояние Codex VS Code»** удаляет только устаревшие PID/время запуска/HWND после проверки, что точный управляемый экземпляр не работает. Профили, авторизация, workspace, настройки и расширения сохраняются. Отдельное действие создаёт ярлык **Codex VS Code**, не заменяя обычный ярлык Visual Studio Code.

## Безопасность

Приложение работает локально, не содержит телеметрии и не записывает содержимое авторизации или полное окружение процессов в логи. Никогда не публикуйте реальные `auth.json`. Подробности — в [SECURITY.md](SECURITY.md).
