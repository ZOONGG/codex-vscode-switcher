# Codex VS Code Switcher

Codex VS Code Switcher — новое независимое Windows-приложение, которое в будущем будет переключать изолированные профили Codex внутри отдельного экземпляра Visual Studio Code.

Сейчас репозиторий находится на этапе **bootstrap и изоляции**. Границы хранения, идентификаторы продукта, WPF-интерфейс, настройки и контракты будущей интеграции готовы. Поиск и запуск VS Code, активация профиля, повторное открытие workspace, отслеживание окна и привязка оверлея ещё не реализованы.

При выборе профиля программа безопасно сообщает:

> Переключение профилей VS Code ещё не реализовано в этой подготовительной сборке.

Файлы авторизации при этом не изменяются.

## Гарантии изоляции

Изменяемые данные нового приложения находятся только в собственных каталогах:

```text
%LOCALAPPDATA%\CodexVsCodeSwitcher
├── settings.json
├── profiles.json
├── profile-status.json
├── logs
├── backups
├── transactions
├── VSCodeData
├── VSCodeExtensions
└── last-workspace.json

%USERPROFILE%\.codex-vscode-profiles
```

Следующие каталоги защищены программной политикой. Чтение для копирования, запись, перемещение, удаление, замена и резервное копирование отклоняются до изменения файловой системы:

```text
%USERPROFILE%\.codex
%LOCALAPPDATA%\CodexProfileOverlay
```

Основной аккаунт Codex/ChatGPT Desktop и данные исходного приложения Codex Swap Account остаются вне границ нового продукта.

## Что работает

- уникальные exe, assembly, namespace, mutex, AppUserModelID, автозапуск, ярлыки, installer identity и пути данных;
- WPF-панель, трей, глобальные хоткеи, темы, русский/английский интерфейс, настройки и безопасные метаданные профилей;
- раздел «Интеграция с VS Code» с подготовленными параметрами;
- UI статусов и лимитов для профилей в отдельном корне;
- минимальные allowlist-бэкапы: не более 10 МБ на файл, 25 МБ на транзакцию, пяти копий и 100 МБ суммарно;
- только чтение и планирование будущей явной миграции из `.codex-profiles`;
- тесты, safety scan, сборка и portable-публикация.

## Что намеренно отключено

- поиск и запуск VS Code;
- передача `CODEX_HOME` процессу VS Code;
- реальное переключение профилей;
- привязка панели к окну VS Code;
- закрытие, запуск или перезапуск ChatGPT/Codex Desktop;
- чтение или замена `%USERPROFILE%\.codex\auth.json`;
- рекурсивные копии `CODEX_HOME`;
- автоматическая миграция;
- автоматические обновления.

Канал обновлений не настроен. Запросы к релизам исходного проекта не выполняются.

## Будущая миграция

`%USERPROFILE%\.codex-profiles` рассматривается как источник только для чтения. Сейчас создаётся лишь план с top-level файлами `auth.json` и `config.toml` меньше 10 МБ. Копирование не выполняется.

Будущий процесс потребует явного подтверждения, сохранит источник и исключит сессии, rollout JSONL, базы данных, логи, кэши и вложения.

```powershell
.\publish.ps1
```

Результат:

```text
artifacts\publish\CodexVsCodeSwitcher.exe
artifacts\CodexVsCodeSwitcher-win-x64-portable.zip
artifacts\SHA256SUMS.txt
```

## Безопасность

Приложение работает локально, не содержит телеметрии и не записывает содержимое авторизации в логи. Никогда не публикуйте реальные `auth.json`. Подробности — в [SECURITY.md](SECURITY.md).

## Статус

Это подготовительная сборка, а не готовый переключатель аккаунтов VS Code.
